# Real-Time Whiteboard

A full-stack real-time whiteboard app with collaborative drawing and user authentication.

## Features
✅ Real-time drawing with multiple users  
✅ User registration / login  
✅ Save / load canvas  
✅ Responsive design  

## Tech stack
- Node.js + Express (backend)
- React (frontend)
- MongoDB (database)
- Socket.IO (real-time updates)

## Getting Started

### Backend
```bash
cd backend
npm install
npm start
